## What I work on

**Risk, rates and models that have to hold up in production.** My day job is market risk at scale: margin, VaR and end-of-day processes that banks depend on every morning. My academic work asks how far machine learning can push classical quantitative finance in a market like Colombia's.

> I came to quant finance from macroeconomics. That shapes how I build models: start from the economic mechanism, then let the data and the code test whether it survives contact with the real market.

`market risk` · `quant finance` · `reinforcement learning` · `econometrics` · `Python`
